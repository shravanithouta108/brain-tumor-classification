# Brain Tumor Classification from MRI Images Using CNN

A Convolutional Neural Network (CNN) that classifies brain MRI scans into four categories: glioma, meningioma, pituitary tumor, or no tumor.

## Problem Statement

Manually reviewing MRI scans to detect and classify brain tumors requires expert radiologists and is time-consuming. This project explores whether a CNN can learn to classify brain MRI images into tumor types using a labeled dataset, as a foundation for future decision-support tooling.

## Objectives

- Build a CNN capable of classifying brain MRI images into 4 categories
- Achieve reliable, honestly-evaluated performance on unseen test data
- Design the project so it can be extended into a larger system (transfer learning, explainability, web interface) as a major project

## Features

- Custom CNN built and trained from scratch (no pretrained models)
- Data augmentation to improve generalization
- Early stopping to prevent overfitting
- Full evaluation pipeline: accuracy, precision, recall, F1-score, confusion matrix
- Modular, configurable codebase (all key settings in one config file)

## Dataset

**Source:** [Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset) by Masoud Nickparvar (Kaggle)

- 4 classes: glioma, meningioma, pituitary, notumor
- Training set: 5,600 images (1,400 per class, balanced)
- Testing set: 1,600 images (400 per class, balanced)
- Format: JPG, variable original dimensions (resized to 128×128 during preprocessing)

## Installation

```bash
git clone https://github.com/shravanithouta108/brain-tumor-classification.git
cd brain-tumor-classification
```

2. Create and activate a virtual environment (Python 3.10–3.13 required for TensorFlow compatibility):
```bash
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # macOS/Linux
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Download the dataset from Kaggle (see Dataset section above) and place it in `dataset/`.

## How to Run

**1. Verify the dataset is set up correctly:**
```bash
python src/inspect_dataset.py
```

**2. (Optional) View sample images per class:**
```bash
python src/view_samples.py
```

**3. Train the model:**
```bash
python src/train.py
```
This trains the CNN, applies early stopping automatically, and saves the model to `models/brain_tumor_cnn.keras`.

**4. Evaluate the trained model:**
```bash
python src/evaluate.py
```
This generates training curves, a confusion matrix, and a classification report in `outputs/`.

## Model Architecture

A CNN with:
- 3 convolutional blocks (32 → 64 → 128 filters, each followed by max pooling)
- Data augmentation layers (horizontal flip, slight rotation, slight zoom) applied only during training
- A dense layer (128 units) with dropout (0.5) to reduce overfitting
- A softmax output layer (4 classes)

Total parameters: ~3.3 million

## Results

Evaluated on 1,600 unseen test images:

| Metric | Value |
|---|---|
| **Test Accuracy** | **90.06%** |
| **Test Loss** | **0.60** |

| Class | Precision | Recall | F1-score |
|---|---|---|---|
| Glioma | 0.95 | 0.77 | 0.85 |
| Meningioma | 0.89 | 0.85 | 0.87 |
| Notumor | 0.83 | 1.00 | 0.91 |
| Pituitary | 0.95 | 0.98 | 0.97 |

**Observations:**
- The model perfectly identifies "no tumor" cases (100% recall) and performs very well on pituitary tumors (98% recall).
- Glioma is the most challenging class to classify (77% recall), most often confused with meningioma or notumor — consistent with gliomas being visually diffuse and appearing in varied brain locations, unlike the more localized/well-defined patterns of the other classes.
- An initial baseline model (no augmentation, no early stopping) reached 88.4% accuracy but showed clear overfitting (rising validation loss). Adding early stopping and carefully-tuned data augmentation improved both accuracy (to 90.06%) and prediction reliability (test loss reduced from 1.51 to 0.60).

See `outputs/confusion_matrix.png` and `outputs/training_curves.png` for full visualizations.

## Limitations

- Trained on a single public dataset; performance on MRI scans from different machines/hospitals is untested.
- Glioma classification accuracy is noticeably lower than other classes.
- No explainability — the model does not indicate *why* it made a prediction (planned for major project via Grad-CAM).
- No user interface currently — model is evaluated via scripts only.
